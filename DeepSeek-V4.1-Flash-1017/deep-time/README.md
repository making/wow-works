# 138億年

ビッグバンから現在までの138億年を、途切れのないひとつの映像として描く。約2分55秒。

## 実行

```
open index.html
```

または任意の静的サーバから `index.html` を開く。外部アセット、CDN、ビルドは不要。WebGL2 と Web Audio を使用する。

## 操作

- 画面下のタイムラインをドラッグすると任意の時代へ移動する
- `Space` 一時停止 / `M` 消音 / `←` `→` 4秒移動

## 構成

`index.html` のみ。すべての画像はフラグメントシェーダとパーティクルシェーダでリアルタイムに生成し、音は Web Audio のオシレータで合成する。

- 背景: ドメインワープした fbm による星雲、星野、最終散乱面
- 前景: 2万4千点の頂点シェーダで形成をモーフィング(プラズマ、殻、フィラメント、銀河円盤、原始惑星系円盤、惑星)
- ポストプロセス: HDR バッファ、ブルーム、ACES トーンマップ、粒子、ビネット
- 時間軸: 各ビートの宇宙時刻・温度・赤方偏移は実測値に基づく

## 数値について

各段階の宇宙時刻、温度、赤方偏移は標準的な宇宙論の値(プランク期 10⁻⁴³ 秒、再結合 38万年・3000 K・z=1100、現在 2.725 K など)を用いている。映像の進行は映画的に圧縮してあり、対数時間軸そのものではない。
